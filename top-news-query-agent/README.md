# Top News Query Agent

This agent returns the top Google News headlines for a location using a public RSS feed.

## Run it

From this folder:

python3 main.py "top news in London"

Or start in interactive mode:

python3 main.py

## Example output

   Link: https://news.google.com/rss/articles/...
   Summary: The Office for National Statistics said inflation...

## Notes

- No API key required
- Results come from Google News RSS
- Use location names like city, region, or country
